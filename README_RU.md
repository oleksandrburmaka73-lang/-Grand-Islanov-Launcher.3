# Grand Islanov RP Launcher — редактируемая версия

## Где менять дизайн и картинки
- `app/src/main/assets/index.html` — весь интерфейс, тексты, карточки и цвета.
- `app/src/main/assets/images/hero-launcher.png` — главная фоновая иллюстрация. Можно заменить своей картинкой, сохранив имя файла.
- Новые изображения положите в `app/src/main/assets/images/` и укажите их имена в `index.html`.

## Сборка
Загрузите содержимое проекта в GitHub с сохранением папок, затем откройте Actions → Build Grand Islanov Launcher APK. После успешной сборки скачайте Artifact.

## Важно
Это Android WebView-оболочка. В ней есть демонстрационные экраны магазина/кейсов, но нет настоящих платежей, серверной авторизации, выдачи предметов или запуска игрового клиента. SA-MP использует UDP-протокол; проверка статуса через обычный браузерный HTTP-запрос не подтверждает доступность игрового сервера. Для реального входа нужен совместимый клиент и поддерживаемый способ запуска/передачи IP:порта. Не используйте чужой клиент/ресурсы без разрешения.
